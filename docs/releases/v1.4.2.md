# Answering v1.4.2

发布状态：尚未正式发布。源码回归与源码离线自检通过，Windows EXE 已构建；本机企业应用控制策略阻止启动未签名 EXE，因此正式 EXE 自检未完成，未创建此版本的标签或 GitHub Release。下列为待发布版本说明。

重新设计桌面工作台，整理信息密度与操作层级，让批量执行、题库检索和成绩查看更清晰。

- 统一浅灰绿配色、白色圆角卡片、图标、字体层级、表格与控件样式，突出启动和停止操作。
- 设置拆分为“执行与模拟”和“连接与保存”；并发、后台执行、测试开关、用时与分数集中显示。
- 身份和题库的导入按钮移至卡片右上角，增加数量标识和无数据提示；题目列表与详情并排展示，可独立拖动调整比例。
- 增加跟随真实批次状态更新的进度条与分类计数，强调完成成绩和失败原因。
- 底部固定操作栏，运行记录按需展开；小窗口中间工作区可滚动，长路径和状态可悬停查看全文。
- 保留并发上限 30、独立会话、后台执行、98–100 默认得分、最快模式两次校验，以及测试开关与预览分离的流程。

下载 `Answering-Windows-x64-v1.4.2.zip`，完整解压后运行 `Answering/Answering.exe`，须保留 `_internal` 文件夹。完整包包含运行库、OCR 模型、网页资源、界面图标和备用 Chrome，无需安装 Python。单独附件 `Answering.exe` 依赖完整包。

附件同时提供源码 ZIP、中文说明 `UserGuide.md`、本次实际验证记录 `Validation.md`、文件清单 `release-manifest.json` 和 `SHA256SUMS.txt`。功能验证及未覆盖范围以 `Validation.md` 为准。
