# Answering v1.4.1

Windows 10/11 64 位版本，调整答案校验标注、预览触发方式、默认分数和可拖动布局。

- “最快完成”标注改为“仍进行两次答案校验”，继续完整执行两次复核和提交后实际评分核对。
- “测试开关”只切换批次模式，不再自动展示试卷；点击“重新生成 / 预览试卷”时才打开预览，开关关闭时也可预览。
- 得分范围默认 98–100。旧默认 91–99 在首次升级时更新，保留其他自定义范围。
- 新增上方信息区与批量进度/成绩区之间的上下拖动分隔条，成绩列表可随区域扩大；保留人员与题库之间的左右拖动，两个比例均自动保存和恢复，分区不可完全折叠。

## 下载与验证

下载 `Answering-Windows-x64-v1.4.1.zip`，完整解压后双击 `Answering/Answering.exe`。无需安装 Python，须保留 `_internal` 文件夹。

附件包括源码包、`UserGuide.md`、`Validation.md`、`release-manifest.json` 和 `SHA256SUMS.txt`。具体测试结果见 `Validation.md`。单独的 `Answering.exe` 依赖完整包，不能独立运行。

保留并发和后台执行功能。验证包括最快模式的答案变化修复、显式预览、分数默认值迁移、布局比例恢复，以及正式 EXE 的双会话本地自检。真实网站操作仍止于登录，自动作答用于本地模拟试卷。
