# 网页自动登录助手 v1.3.0

Windows 10/11 64 位版本，发布日期：2026-10-19。

## 下载文件

- `WebLoginAssistant-Windows-x64-v1.3.0.zip`：完整免安装包，包含 EXE、运行库、OCR 模型、网页资源及备用 Chrome。解压后双击 `WebLoginAssistant/WebLoginAssistant.exe`。
- `WebLoginAssistant.exe`：同一版本的启动程序，依赖完整包中的 `_internal` 文件夹，不能单独运行。
- `WebLoginAssistant-Source-v1.3.0.zip`：源码、依赖锁定文件、测试、打包脚本和中文说明。
- `UserGuide.md`、`Validation.md`：中文使用步骤与验证范围。
- `release-manifest.json`、`SHA256SUMS.txt`：文件大小及 SHA-256 校验值。

## 功能

批量导入身份、浏览器自动选择、区县及考生登录、验证码本机识别三次失败后继续下一人、已完成与未完成统计，以及保留网页的三选项停止控制。

开启本地测试后，每人随机生成包含单选、多选、判断的 100 题试卷，每题 1 分，满分 100 分。默认 10 分钟，可设置分钟范围或最快完成；默认最低分 90、范围 91–99，模拟成绩按范围变化。作答后进行两次复核，提交独立评分，将实际得分和用时写入日志及统计。

## 验证

已通过 54 项不同的自动化测试、公开入口页面检查和正式 EXE 离线自检。EXE 自检本地模拟得分为 94/100；已完成真实 1 分钟计时测试，默认 10 分钟调度使用可控时钟验证。

未提交真实账号登录，真实验证码识别率未统计；尚未在另一台完全未安装 Python 的 Windows 机器上验证。真实网站考试作答不在此版本范围内。

软件包不包含用户身份表、原始题库、账号日志或真实验证码截图。完整操作及边界请阅读附件说明。
