# Answering v1.3.1

Windows 10/11 64 位版本。本次将原“网页自动登录助手”统一改名为 Answering，保留现有功能、数据格式及历史版本。

## 更新内容

- 仓库、软件界面、程序文件及构建配置统一使用 Answering 名称。
- 首次启动继承旧版设置，新版已有设置优先；保留旧设置和用户结果文件。
- 发布文件名、下载链接及 SHA-256 校验清单统一更新。

## 下载文件

- `Answering-Windows-x64-v1.3.1.zip`：完整免安装包，包含 EXE、运行库、OCR 模型、网页资源及备用 Chrome。完整解压后双击 `Answering/Answering.exe`，无需安装 Python。
- `Answering.exe`：同一版本的启动程序，依赖完整包中的 `_internal` 文件夹，不能单独运行。
- `Answering-Source-v1.3.1.zip`：源码、锁定依赖、测试、构建脚本和中文说明。
- `UserGuide.md`、`Validation.md`：中文使用说明与本次实际验证记录。
- `release-manifest.json`、`SHA256SUMS.txt`：文件大小及 SHA-256 校验值。

## 验证与兼容

发布前运行自动化测试、旧设置迁移测试及正式 EXE 离线自检，具体结果和跳过项见附件 `Validation.md`。离线自检使用随附 Chrome 和虚构身份，完成本地 100 题作答、两次复核、评分及统计导出。

真实网站操作仍止于登录；自动作答、分数范围和用时设置作用于本地模拟试卷。旧版 v1.3.0 的附件和发布记录继续保留。
