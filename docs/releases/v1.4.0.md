# Answering v1.4.0

Windows 10/11 64 位版本，新增并发和后台执行功能。

- 并发数量可设置为 1–30，默认 10。完成或失败后自动补位，每个身份的登录、答题、复核和评分共占一个名额。
- 每批使用一个浏览器，各身份拥有独立会话、Cookie、本地存储和试卷。
- 新增“后台执行（隐藏浏览器）”，默认开启，运行中浏览器不弹出窗口。取消后可观察执行流程；试卷预览独立显示。
- 运行中仍可查看人员、成绩和日志，搜索题库、打开结果目录；本批次配置保持固定。
- 停止支持等待全部活动人员完成、立即中止全部活动任务及取消；保留未开始人员，统计文件记录实际状态及执行配置。
- 继承旧版设置，保留 v1.3.0 和改名版本的提交及标签。

## 下载与使用

下载 `Answering-Windows-x64-v1.4.0.zip`，完整解压后双击 `Answering/Answering.exe`。完整包包含运行库、OCR 模型、网页资源及备用 Chrome，无需安装 Python；必须保留 `_internal` 文件夹。

`Answering-Source-v1.4.0.zip` 为源码。`UserGuide.md`、`Validation.md` 为中文说明和本次验证记录，`release-manifest.json`、`SHA256SUMS.txt` 提供文件大小与校验值。单独的 `Answering.exe` 依赖完整包，不能独立运行。

验证覆盖并发调度、停止控制、浏览器会话隔离、两人并发登录及本地答题、界面响应，以及正式 EXE 使用随附 Chrome 的双会话离线自检。具体结果与跳过项见 `Validation.md`。

真实网站操作仍止于登录，自动作答和分数/用时设置用于本地模拟试卷。
